jQuery

Biblioteca de JavaScript creada para simplificar determinadas tareas del desarrollo web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que proporciona una sintaxis sencilla para realizar tareas como seleccionar elementos HTML, manejar eventos, modificar contenido y crear efectos visuales.

Sintaxis básica

Una de las características principales de jQuery es el uso del símbolo $ para seleccionar elementos. 

$("#boton").click(function() {
    alert("Mensaje desde jQuery");
});

Ventajas y desventajas

Ventajas

Facilita algunas tareas, utiliza una sintaxis sencilla y permite implementar efectos de manera práctica.

Desventajas

Algunas funciones que antes requerían jQuery ahora pueden realizarse directamente con JavaScript moderno.
