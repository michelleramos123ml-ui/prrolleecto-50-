Web Hosting y Dominios

Conceptos fundamentales para publicar un sitio web y hacerlo accesible mediante Internet.

¿Qué es Web Hosting?

El Web Hosting es un servicio que permite almacenar los archivos y recursos de un sitio web en un servidor conectado a Internet.

Gracias al hosting, los usuarios pueden acceder al contenido de una página desde diferentes dispositivos.

Tipos de Hosting

Hosting compartido

Diferentes sitios web comparten los recursos de un mismo servidor.

VPS

Un servidor físico se divide en diferentes servidores virtuales con recursos asignados.

Hosting en la nube

Utiliza una infraestructura de servidores conectados para distribuir los recursos.

¿Cómo funciona Vercel?

Vercel es una plataforma de despliegue utilizada para publicar sitios web y aplicaciones. Puede conectarse con repositorios de GitHub para facilitar el proceso de publicación y actualización.

¿Qué es un dominio?

Un dominio es un nombre único que permite identificar y localizar un sitio web en Internet.

mimis.com

TLD y subdominios

Un TLD es la extensión que aparece al final de un dominio. Algunos ejemplos son: .com, .net y .org.

Un subdominio es una sección adicional que se encuentra antes del dominio principal.

tienda.mimis.com

Proceso de propagación DNS

El DNS permite relacionar un nombre de dominio con la dirección del servidor donde se encuentra alojado el sitio web.
