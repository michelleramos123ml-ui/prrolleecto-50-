TECNOLOGÍA WEB

JavaScript

Lenguaje de programación utilizado para agregar comportamiento e interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite crear contenido dinámico e interactivo en los sitios web. Puede utilizarse para responder a las acciones realizadas por los usuarios, modificar elementos de una página, validar formularios y realizar diferentes procesos.

HTML, CSS y JavaScript

HTML

Define la estructura y el contenido de una página web.

CSS

Define la apariencia, colores, tamaños y distribución de los elementos.

JavaScript

Permite agregar comportamiento, interacción y funciones dinámicas.

Conceptos básicos

Variables

Permiten almacenar información que puede utilizarse durante la ejecución del programa.

Funciones

Son bloques de código creados para realizar una tarea determinada.

Eventos

Son acciones que ocurren en una página, como hacer clic sobre un botón.
