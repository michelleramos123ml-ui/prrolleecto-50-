JSON

Formato utilizado para almacenar e intercambiar información entre aplicaciones.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar información de manera organizada y fácil de interpretar por diferentes aplicaciones.

Estructura de JSON

JSON utiliza principalmente objetos, arreglos y pares de clave-valor para organizar los datos. 

{
    "nombre": "MIMI'S Classic",
    "precio": 35,
    "categoria": "Calzado",
    "disponible": true
}

Objeto JavaScript y cadena JSON

Objeto JavaScript

const producto = {
    nombre: "MIMI'S Classic",
    precio: 35,
    disponible: true
};

JSON

{
    "nombre": "MIMI'S Classic",
    "precio": 35,
    "disponible": true
}

JSON en aplicaciones web

Las aplicaciones web utilizan JSON para enviar y recibir información entre el navegador y un servidor. Por ejemplo, una tienda en línea podría solicitar mediante una API la información de sus productos, precios y disponibilidad.
